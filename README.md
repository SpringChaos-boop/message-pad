# 📓 Блокнот 

**Версия:** 1.2
**Платформа:** Tampermonkey / Violentmonkey / Greasemonkey
**Язык интерфейса:** русский
**Назначение:** компактный плавающий блокнот для шаблонов сообщений, заметок и быстрых записей, который не мешает работе страницы.

## 📖 Описание

Скрипт добавляет в правый нижний угол страницы круглую кнопку **📓**. По клику раскрывается панель-блокнот с записями. Каждая запись — это отдельный блок с **редактируемым заголовком** и **редактируемым текстом**. Блоки можно сворачивать, перетаскивать, копировать их содержимое в буфер и удалять. Всё содержимое автоматически сохраняется между сессиями.

## ✨ Возможности

### Основные
- **Плавающая кнопка `📓`** — открывает и закрывает панель. Позиция фиксированная.
- **Записи-блоки** — каждая запись хранится отдельно и сворачивается по стрелке ▾.
- **Редактируемый заголовок** — кликните и печатайте. `Enter` переводит курсор в текст записи.
- **Редактируемое содержимое** — можно вводить и вставлять любой текст, включая многострочный и с базовым форматированием (HTML сохраняется).
- **Добавление записи** — кнопка `＋` в шапке. Новая запись сразу фокусируется для ввода заголовка.
- **Удаление записи** — кнопка `✕` с подтверждением.
- **Автосохранение** — каждое изменение уходит в хранилище Tampermonkey. Данные не потеряются при закрытии вкладки или браузера.

### Расширенные
- **🖱 Перетаскивание блоков** — ручка `⋮⋮` слева от стрелки. Зажмите и тяните, чтобы изменить порядок записей. Порядок сохраняется.
- **📋 Копирование содержимого** — кнопка `⧉` в шапке блока копирует чистый текст записи в буфер обмена. При успехе иконка на 1,2 секунды меняется на `✓`.
- **↔ Ресайз панели** — диагональный уголок в левом верхнем углу панели. Тяните, чтобы изменить ширину и высоту. Размер запоминается.
- **🌙 Тёмная тема** — кнопка `☾`/`☀` в шапке. Палитра тёмной темы построена на тех же оттенках, что и светлая.
- **`Escape`** — если вы редактируете, снимает фокус с поля; если не редактируете — закрывает панель.

## 🚀 Установка

1. Установите расширение **Tampermonkey** (Chrome, Edge, Firefox, Opera) или **Violentmonkey**.
2. Откройте панель управления расширением → **«Создать новый скрипт»**.
3. Удалите шаблон и вставьте код скрипта целиком.
4. Сохраните (`Ctrl+S`) и обновите любую страницу.
5. В правом нижнем углу появится кнопка `📓`.

## 🕹 Использование

| Действие | Как |
|---|---|
| Открыть / закрыть блокнот | Клик по `📓` в углу страницы |
| Свернуть / развернуть блок | Стрелка `▾` слева в шапке блока |
| Изменить заголовок | Клик по заголовку, ввод текста |
| Перейти от заголовка к тексту | `Enter` в заголовке |
| Изменить текст записи | Клик по области текста, ввод |
| Добавить запись | Кнопка `＋` в шапке панели |
| Удалить запись | Кнопка `✕` в шапке блока (с подтверждением) |
| Скопировать текст записи | Кнопка `⧉` в шапке блока |
| Изменить порядок блоков | Тянуть за `⋮⋮` влево-вверх/вниз |
| Изменить размер панели | Тянуть диагональный уголок в левом верхнем углу панели |
| Переключить тему | Кнопка `☾` / `☀` в шапке панели |
| Закрыть панель с клавиатуры | `Esc` (вне режима редактирования) |

### Совместимость

| Браузер | Статус |

## 🛠 Возможные улучшения (для будущих версий)

- **Shadow DOM** для гарантированной изоляции от CSS страницы.
- **Pointer-events drag** вместо нативного HTML5 — стабильнее в Safari и на тач-устройствах.
- **Кнопка «свернуть / развернуть все»** в шапке.
- **Экспорт / импорт** всех записей в JSON (резервная копия).
- **Горячая клавиша** открытия панели (например, `Ctrl+Shift+Space`).
- **Форматирование текста** — мини-тулбар `B / I / U` для блока.
- **Пресеты шаблонов** — отдельный список с быстрым копированием.
- **Синхронизация**.
- **Поиск по записям** — фильтр в шапке панели.

## ⚠️ Известные ограничения

1. **Блокировка клавиш не абсолютна.** 
2. **Сохранение HTML.** Если вставить в запись картинку из буфера как `data:image/png;base64`, она сохранится в хранилище (может раздуть его). Не рекомендуется вставлять большие изображения.
